	% --- Slide 4: The Market (foundational dependency, not a feature) ---
	\begin{frame}
		\frametitle{The Foundational Layer Every AI Company Will Require}
		Any AI product whose value depends on reading, structuring, or reasoning over real documents faces the same dependency \textemdash{} and a competitor built on a solved version of it carries a structural, compounding advantage.

		\begin{columns}[T]
			\column{0.49\textwidth}
			\begin{block}{Not a Feature. A Survival Dependency.}
				\begin{itemize}
					\item An extraction error is not local \textemdash{} every downstream layer built on top of a wrong read inherits it.
					\item As the AI market matures past novelty into reliability, the ingestion layer stops being invisible and becomes the differentiator.
					\item \textbf{The gap compounds, it does not reset.} On every model release, a Citadel-based competitor re-embeds structured data in minutes; a competitor without it re-runs full extraction from raw source \textemdash{} the same race, run again, every cycle, widening the distance each time.
				\end{itemize}
			\end{block}

			\column{0.49\textwidth}
			\begin{block}{Who Already Depends On It}
				\begin{itemize}
					\item \textbf{New AI companies}, at the build-vs-buy decision for ingestion \textemdash{} the same default shift that made hand-rolled payments infrastructure disappear once Stripe existed.
					\item Every vertical AI company reading real-world documents today \textemdash{} legal, financial, compliance, healthcare, and beyond.
					\item Enterprises building internal AI and agents over their own document corpora \textemdash{} direct buyers, not only vendors.
				\end{itemize}
			\end{block}
		\end{columns}

	% --- Slide 8: What Survives the Compilation ---
	\begin{frame}
		\frametitle{Compiling Unstructured State into Persistent Knowledge}
		Citadel turns raw enterprise files into a persistent asset with properties a reader can rely on:

		\begin{columns}[T]
			\column{0.49\textwidth}
			\textbf{Nothing Is Lost}
			\begin{itemize}
				\item Every document keeps its own layout, hierarchy, and context \textemdash{} nothing is flattened into plain text.
				\item Headings, footnotes, and nested sections stay connected to what they describe.
				\item Tables stay tables \textemdash{} never collapsed into paragraphs that lose their meaning.
			\end{itemize}

			\column{0.49\textwidth}
			\textbf{Nothing Is Untraceable}
			\begin{itemize}
				\item Every answer traces back to exactly where it came from in the source document.
				\item Only real content survives \textemdash{} formatting noise never pollutes what a model reads.
				\item Any document becomes something every downstream tool can query directly.
			\end{itemize}
		\end{columns}
	\end{frame}

	% --- Slide 10: Planning vs Execution ---
	\begin{frame}
		\frametitle{A Clear Separation of Concerns: Planning vs. Execution}
		Large Language Models excel at resolving ambiguity and planning tasks, but collapse when handling precise state maintenance.

		\begin{columns}[T]
			\column{0.49\textwidth}
			\textbf{The Reasoning Layer (AI Models)}
			\begin{itemize}
				\item Decodes semantic user intent.
				\item Formulates comprehensive declarative plans.
				\item Selects core computational milestones.
			\end{itemize}

			\column{0.49\textwidth}
			\textbf{The Execution Substrate (Citadel)}
			\begin{itemize}
				\item Answers every figure directly from source, never from prediction.
				\item Validates layout, table data, and cell alignment.
				\item Eliminates computational hallucination with reproducible outputs.
			\end{itemize}
		\end{columns}
		\vfill
		\centering
		{\color{CitadelHighlight}\bfseries Reasoning remains probabilistic. Knowledge execution remains deterministic.}
	\end{frame}
