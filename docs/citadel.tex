	% --- Slide 5: The Market (foundational dependency, not a feature) ---
	\begin{frame}
		\frametitle{The Foundational Layer Every AI Company Will Require}
		Any AI product whose value depends on reading, structuring, or reasoning over real documents faces the same dependency \textemdash{} and a competitor built on a solved version of it carries a structural, compounding advantage.

		\begin{columns}[T]
			\column{0.49\textwidth}
			\begin{block}{Not a Feature. A Survival Dependency.}
				\begin{itemize}
					\item An extraction error is not local \textemdash{} every downstream layer built on top of a wrong read inherits it.
					\item As the AI market matures past novelty into reliability, the ingestion layer stops being invisible and becomes the differentiator.
					\item \textbf{The gap compounds, it does not reset.} On every model release, a Citadel-based competitor re-embeds structured data in minutes; a competitor without it re-runs full extraction from raw source \textemdash{} the same race, run again, every cycle, widening the distance each time.
				\end{itemize}
			\end{block}

			\column{0.49\textwidth}
			\begin{block}{Who Already Depends On It}
				\begin{itemize}
					\item \textbf{New AI companies}, at the build-vs-buy decision for ingestion \textemdash{} the same default shift that made hand-rolled payments infrastructure disappear once Stripe existed.
					\item Enterprises building internal AI and agents over their own document corpora \textemdash{} direct buyers, not only vendors.
				\end{itemize}
			\end{block}
		\end{columns}
		\vfill
		\centering
		{\color{CitadelHighlight}\bfseries Payphones did not lose to a better payphone. They lost when the infrastructure underneath calling changed. Citadel is that shift, for enterprise data.}
	\end{frame}
