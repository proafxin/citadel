# Table Merge

These tables were found in the same columns of one sheet, one after another, top to bottom, with a gap
between them in the source. Each is shown by its index, its column names and value-kinds, its row count, and
its title/notes if it has any. Decide which are really fragments of one table split apart — a continuation
onto the next block, a repeated export with the header struck off after the first — versus genuinely separate
tables that happen to share the same shape (different subjects, different time periods, different titles).

Group indices that belong together into one list, in the top-to-bottom order they should be read in. A table
that stands alone is its own single-item list. Every index must appear in exactly one group.

Signs two are the same table continuing: identical columns in the same order; the later one has no header row
of its own, or repeats the same header; no title, or the same title; nothing in the content marks a change of
subject.

Signs two are genuinely different tables that only coincide in shape: different titles; a subject named in
one that does not match the other (a different region, period, or category); each reads as complete on its
own rather than continuing something.
