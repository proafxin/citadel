# Table Merge

These tables were found in the same columns of one sheet, one after another, top to bottom, with a gap between
them in the source. Each is shown by its index, its column names and value-kinds, its row count, and its
title/notes if it has any.

Decide which of them are really fragments of one table split apart, and which are genuinely separate tables.

Group indices that belong together into one list, in the top-to-bottom order they should be read in. A table
that stands alone is its own single-item list. Every index must appear in exactly one group.
