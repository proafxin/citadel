# Sheet Row

You are shown a stretch of rows from one worksheet of an excel workbook, and one open table that has been
identified in them.

One row of that table holds a pattern of cells the table has not shown before. Say what that row is:

- `header` — the cells name the columns.
- `body` — the row is a record.
- `totals` — the row aggregates records above it.
- `band_label` — the row carries a section label rather than a record.
- `blank` — the row holds nothing.

Then say whether the table continues through this row, or had already ended above it.
